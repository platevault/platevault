# Localisation gate

The production message catalogues are `messages/en-GB.json` and `messages/pt-BR.json`, compiled by Paraglide into `src/paraglide/`. Product code imports messages and locale helpers from `src/lib/i18n.ts`; generated modules are not a direct production-code boundary.

User-visible strings belong in the base catalogue and are checked by ESLint (`pv/no-user-string`, `pv/no-js-plural`, `pv/require-disable-reason`) and `scripts/check-copy.mjs`. The lint scripts also check catalog duplicate/error-code issues and exact locale key parity.

ESLint disables require explicitly named rules and a short reason of at least three words. Blanket `eslint-disable` directives are not allowed. A `prototype_*`, `simulation_*`, `seed_*`, or `setup_demo_*` message key is forbidden in shipped catalogues; copy lint also rejects prototype/simulation/demo wording in production copy.

Run `pnpm --filter @platevault/desktop-ui lint` after changing catalogues, locale settings, or user-visible copy.
