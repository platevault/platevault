# T1 wireframes: onboarding, setup and Settings

Track T1 of the PlateVault prototype. Binding sources: `../HIGH-LEVEL-DESIGN.md`
(IA, routes, tokens, components, copy rules), spec 064 (LIB-FR-01 to LIB-FR-08,
LIB-AC-01, -04, -05, -07, -11, -12), decisions D08, D11, D16, D18, and journeys
J19 (registration and indexing), J18 (orientation), J10 (Settings) and J15
(equipment and sites). J10, J15 and J18 are older; they supply intent only, and
the HLD wins where they disagree (§14).

Everything here is prototype behaviour over the fixture store. No screen claims
real file access, real network lookups or backend behaviour; simulated parts
say "Prototype".

## Intent and constraints

- Product: local-first astrophotography library. Audience: amateur and advanced
  imagers in long, often night-time desk sessions; keyboard matters.
- Dials: variance 3 (centred, calm), motion 2 (open/close fades only),
  density 7 (rows 32 px comfortable; dense tables, 14 px body).
- Tokens: Tailwind defaults plus the shadcn variables in `src/index.css`; one
  accent (`primary`), status colours only through `StatusBadge`.
- Primitives: shadcn base-nova on Base UI; shared app components from
  `src/components/app/*`. T1 adds track components only under
  `src/features/t1/**`.
- Writes: catalog and settings data through `commit()` (failed write keeps the
  edit and offers Retry; success records a `saved` Activity event, the audit
  trail of J10 S3 and J15 S5). Onboarding progress flags
  (`settings.onboarding.*`) are UI progress, written directly.
- Viewports: 1280 and 1024 CSS px. At 1024 the sidebar keeps 224 px, so Settings
  sections get about 800 px minus the 13rem section menu.

## Shared T1 components (built first, in isolation)

| Component | Purpose | States (N/A reason) |
|---|---|---|
| `LocationRow` | One registered location: display name, path, role, access, availability, scope, last indexed, frames read; inline recovery notice | default; hover (row actions); focus-visible (actions); active (buttons); disabled (Rescan while this location indexes, reason shown); loading (indexing: Running badge + spinner); empty N/A (a row always has a location); error (Access denied notice with Choose folder again and Retry; Incomplete scope notice naming folders); selected (`aria-current` when opened from `?locationId=`) |
| `AddLocationFlow` | Simulated folder picker, then "Add location" dialog: path, display name (suggested), role | default; focus-visible; disabled (Add while invalid is never disabled: submit shows errors); error (field errors: path already registered, nested, contains a location, name missing or used; failed write with Retry); loading N/A (commits are synchronous) |
| `LocationDetailSheet` | Full record for one location and its actions | default; error (offline, denied, incomplete notices); empty N/A |
| `RemapDialog` | Locate or remap with same-asset proof (D11) | default (review counts); error (no frame matched: refused; verification failed: Retry); disabled (confirm needs at least one verified frame); empty (location holds no frames: refused with reason) |
| `FormField` helpers | Label, input, description, error wired with `aria-invalid` and `aria-describedby` | default, focus-visible, error, disabled |
| `EquipmentTable` sections | Optical trains, cameras, telescopes, filters | default; hover; focus-visible; empty (one next action); error (in-use refusal notice; failed write) |
| `SiteTable` | Sites with Default badge, Set as default, Edit, Remove | default; empty; error; selected (Default site badge) |
| `ReturnNotice` | `?return=` banner with one Back link | default only (structural) |
| `GettingStarted` | Sidebar trigger with progress ring, non-modal flyout checklist | default; hover; focus-visible; active; disabled N/A (always usable); empty N/A (five fixed items); selected (open: `aria-expanded`); done items; gated items with reason and jump link |
| `OrientationTour` | Modal six-stop walk anchored to sidebar items | default; focus-visible (Next has initial focus); disabled N/A (Back is hidden on stop 1 instead) |

## Screens

### `/welcome` Welcome (SetupShell) · J18 context, J19 S1 entry

```
[1 Welcome]-[2 Locations]-[3 Index]
Welcome to PlateVault                                            h1
PlateVault catalogs your astrophotography captures where they already
are, groups them into sessions and prepares exact inputs for PixInsight,
Siril and other processing apps.
┌ What PlateVault does ───────────┐ ┌ What it never does ──────────────┐
│ ✓ Indexes folders in place      │ │ ✕ Moves, renames or deletes files│
│ ✓ Groups frames into sessions   │ │   without a reviewed operation   │
│ ✓ Shows Target coverage and     │ │ ✕ Changes source headers         │
│   optional Project goals        │ │ ✕ Calibrates, stacks or stretches│
│ ✓ Prepares reviewed Views       │ │ ✕ Needs an account or network    │
└─────────────────────────────────┘ └──────────────────────────────────┘
Next: choose the folders that hold your captures. Only Captures is required.
[Set up locations]  [Set up later]
ⓘ Prototype: demo library — skips setup, replaces data in this browser [Load demo library]
```

States: default; resumed (locations exist: primary reads "Continue setup");
focus-visible on all three actions. "Set up later" sets
`onboarding.completedAt` and opens Targets (HLD seam 1). "Load demo library"
opens `ConfirmDialog` (changes: replace prototype data with the demo; unchanged:
theme and density, no real files).

### `/setup/locations` Choose locations · J19 S1-S4, flow A1-A2, LIB-FR-01/02, LIB-AC-01

```
[✓ Welcome]-[2 Locations]-[3 Index]
Choose locations                                                  h1
Register the folders that already hold your files. Registering only records
access and indexing intent; nothing is copied, renamed, moved or deleted.
Captures  (Required)                                              h2
  Light frames to index. Add as many folders as you like.
  ┌ Astro-T7 captures   Captures · Not checked · Online · Not indexed ┐
  │ /Volumes/Astro-T7/Captures                         [Remove]       │
  └───────────────────────────────────────────────────────────────────┘
  [Add another location]           (first time: [Add capture location])
Calibration  (Optional)                                           h2
  Not set.  [Add calibration location] [Set up later]
Results  (Optional)                                               h2
  Not set. You chose to set this up later.  [Add results location]
ⓘ View folders are chosen when you prepare a View. No workspace folder,
  processing app, Project or account is needed.
[Back]                      Add a capture location to continue. [Continue]
```

- Empty (first run): Captures reads "Not set" with "Add capture location"; the
  Continue button is disabled with the visible reason "Add a capture location
  to continue. Captures is the only required role." (J19 S1).
- Omitted optional roles read "Not set" (muted badge), never an error (LIB-AC-01).
  "Set up later" records `onboarding.deferredRoles`; adding a location for the
  role clears it.
- Add flow: picker titled "Choose a capture folder" → dialog "Add location"
  with Path (mono, "Choose a different folder"), Display name (suggested
  "Astro-T7 captures" from volume + folder), Role (fixed per button). Errors
  name the field: "Path: /Volumes/Astro-T7/Captures is already registered as
  Astro-T7 captures." "Path: inside Astro-T7 captures, which already indexes
  this folder." "Display name: enter a name." "Display name: Cold-1 captures
  is already used." Failed write: "Location registration was not saved: the
  catalog write failed. Your change is kept on screen; choose Retry."
- Registration shows access "Not checked" until indexing reads the folder; the
  folder picker already warns when access is denied.

### `/setup/indexing` Index your captures · J19 S5-S7, flow A3-A4, LIB-FR-03, LIB-FR-06, LIB-FR-07, LIB-AC-07

```
[✓ Welcome]-[✓ Locations]-[3 Index]
Index your captures                                               h1
PlateVault reads metadata from each location. Files stay where they are.
Before: location rows (setup mode)       [Back] [Index later] [Start indexing]
Running:
  Files discovered 388 · Metadata read 214 · Unsupported 1 · Unreadable folders 1
  · Completed scope 1 of 3 locations
  Library so far: 6 sessions · 214 frames · Provisional, covers Astro-T7
  captures, Cold-1 captures
  [OperationPanel: Indexing 3 locations · Running · 214 of 388 files · Cancel]
  ┌ Astro-T7 calibration  Calibration · Access denied · Online · Incomplete ┐
  │ ⚠ Access denied. PlateVault could not read this folder; none of its      │
  │   files are marked missing. Other locations keep indexing.               │
  │   [Choose folder again] [Retry]                                          │
  └──────────────────────────────────────────────────────────────────────────┘
  You can browse sessions already read while indexing continues. [Open library]
```

- Loading: OperationPanel (progressbar with stable name, count as value text).
- Partial: the panel settles Partial with both sets named ("… 1 of 3 locations
  incomplete or unavailable").
- Error: denied row notice with Choose folder again (picker at the same path;
  choosing the same folder retries, a different folder updates the
  registration first) and Retry (indexes only that location; sessions read
  from Captures are untouched, J19 S7).
- Interrupted (after reload): the panel shows Interrupted with Retry.
- "Open library" sets `completedAt` and opens Targets, where the orientation
  tour starts (J18 S1). "Index later" does the same without indexing.

### `/settings/appearance` Appearance · J10 S2, S9

- Theme: radio cards Dark (default, for night use), Light, Match system
  (follows the OS live). Applies immediately; stored in this browser.
- Density: radio cards Compact (28 px rows), Comfortable (32 px, default),
  Spacious (40 px) with a three-row preview.
- Single-key shortcuts switch ("?, /, [ and G sequences. ⌘K always works").
- "Restore appearance defaults" → ConfirmDialog (changes: Theme → Dark,
  Density → Comfortable, Single-key shortcuts → On; unchanged: library data,
  locations, equipment and sites). Disabled with the reason "Appearance already
  uses the defaults." when nothing differs.
- Language: out of scope (HLD §14); not shown.

### `/settings/locations` Locations · J19 S2-S3, S5, S7, S12-S13, S15; LIB-FR-01, -06, -07; LIB-AC-04, -05, -11; D11

- Header actions: primary "Add location".
- `?return=` → ReturnNotice. `?locationId=` → opens that location's detail
  sheet and marks its row `aria-current`. `?add=captures` opens the add flow.
- Latest indexing run: running or interrupted → OperationPanel; settled → one
  line "Last indexing: Partial · 15 Sep 10:12 · 452 files read …".
- One section per role: Captures, Calibration, Results, Archive. Empty role:
  "Not set" + "Add <role> location".
- Row actions: "Index now" (never indexed) or "Rescan"; menu "More actions for
  <name>": Details, Edit, Locate or remap, Remove.
- Notices: Access denied (Choose folder again, Retry); Incomplete scope
  ("1 folder could not be read: …/2026-09-18. Its frames read Unknown, never
  missing; the session keeps its last-observed metadata." + Rescan);
  Offline ("Cold-1 captures is offline. Its frames keep their last-observed
  metadata and quality decisions and are not offered as inputs." + Locate or
  remap).
- Edit dialog: Display name, Role, "Accepts reviewed filing" switch (`managed`).
- Remove: allowed only when no indexed frame has a copy in the location; else
  the menu item is disabled with "Holds 55 indexed frames. Use Locate or remap
  instead." Confirm lists what changes and that no file is touched.
- Locate or remap: picker → review: Volume evidence (old name + identity vs
  new), counts "Same bytes: 56 · Bytes differ: 1 (refused) · Not found: 0".
  Refusals: no frame matched ("Remap refused: no indexed frame in Cold-1
  captures has the same bytes in /Volumes/Spare/Captures. Nothing changed."),
  same folder ("Choose a different folder, or use Rescan"), folder inside
  another location. Confirm "Remap 56 frames" (ConfirmDialog; unchanged: frame
  identities, quality decisions, View membership, every file). Hash
  verification fault → "Remap not saved: hash verification failed. Nothing
  changed; choose Retry." Refused frames stay in the catalog and read Not found
  in this location, with their decisions kept.

### `/settings/equipment` Equipment · J15 S1-S5; D11; seam 3 (`?return=`)

Sections in order Optical trains, Cameras, Telescopes, Filters. Each table
shows Source as Manual, Detected or Built-in (`StatusBadge kind="source"`).

| Section | Columns | Form fields and rules |
|---|---|---|
| Optical trains | Name, Camera, Telescope, Focal length, Source, Used by | Name (required, unique), Camera (None or record), Telescope (None or record), Effective focal length mm (required, > 0), Notes. A train without parts is accepted (J15 S3) |
| Cameras | Name, Aliases, Sensor, Type, Source | Name (required, unique), Aliases (comma-separated header strings, e.g. INSTRUME), Width px, Height px (whole numbers > 0), Pixel size µm (> 0), Colour sensor checkbox |
| Telescopes | Name, Aliases, Focal length, Aperture, Source | Name, Aliases, Focal length mm (required, > 0), Aperture mm (optional, > 0) |
| Filters | Name, Category, Aliases, Source | Name (required; duplicates refused, J15 S4), Category (Narrowband, Broadband, Dual-band, Other), Aliases |

- Aliases render comma-joined, or "None".
- Saving a Detected record makes it Manual (dialog note says so).
- Remove: in use → refusal notice before anything is written ("ASI2600MM Pro is
  used by 1 optical train: RedCat 51 / ASI2600MM. Edit or remove that train
  first."); trains used by sessions or Projects are refused likewise. Not in use
  → ConfirmDialog; sessions keep their header evidence.
- Empty per section: "No cameras yet. Indexing adds detected cameras from
  INSTRUME headers, or add one yourself." + "Add camera".

### `/settings/sites` Observing sites · J15 S6-S8; J29 seam 7; HLD §14 default site

- Table: Name (Default site badge), Coordinates ("52.09° N, 5.12° E"),
  Elevation, Time zone, Twilight, Minimum altitude; actions Set as default,
  Edit, Remove.
- No default: notice "No default site. Notifications for planned Targets use
  the default site only; PlateVault never picks one for you." The first site is
  not made default automatically (deviation from J15 S6, HLD §14).
- Capture coordinates found in headers that match no site: "52.09° N, 5.12° E ·
  in 6 sessions" + "Add as site" (prefills the form).
- Form: Name; Latitude (−90 to 90, north positive); Longitude (−180 to 180, east
  positive); Elevation m (optional number); Time zone (combobox of IANA zones);
  Twilight (Astronomical or Nautical); Minimum altitude (0 to 90°, default 30);
  "Set as default site" checkbox (off). Each out-of-range value is refused
  inline, naming the field.
- Remove → ConfirmDialog through `removeSite`: removing the default clears it
  and never picks another; reminders bound to the site turn off.

### `/settings/targets` Target lookup · LIB-AC-12, LIB-FR-13, D18

- Switch "Look up Targets online" (`settings.targetLookup.enabled`).
- Provider radio cards: "CDS Sesame (SIMBAD, NED and VizieR)", "SIMBAD only";
  disabled with reason while lookup is off.
- Always-on statement: local search by name, alias or coordinates uses your
  Targets and the bundled catalog and works offline.
- "Test lookup" field (default NGC 7000): loading skeleton while the simulated
  request runs; success shows name, coordinates, object type and provider
  provenance labelled "Prototype: fixture response"; failure (the "Fail next
  Target resolver lookup" fault, or lookup off) names the problem and says local
  Targets and indexed sessions stay usable.

### `/settings/about` About this prototype · J10 S9, J18 S5, S16-S17

- "Prototype" badge; KeyValueList: Version, Data (Empty library or Demo
  library), Stored in (this browser, key `platevault.prototype.v1`), counts.
- Onboarding: "Replay orientation" (opens the tour at stop 1; does not touch the

  state) or a disabled reason "Getting started is shown in the sidebar.";

### Getting started (sidebar footer) · J18 S6-S9, S14-S18; HLD §14 checklist

Trigger above Activity and Settings: "Getting started" + ring + "2/5"; icon-only
with the same ring when the sidebar is collapsed (name "Getting started, 2 of 5
done"). Opens a non-modal flyout to the right (outside click or a nav link
closes it; the page stays usable).

| Item | Done when | Gate and jump link |
|---|---|---|
| Add a capture location | a Captures location exists | Go to Locations |
| Index your captures | a location has `lastIndexedAt` | needs a location; Go to Locations |
| Review a session | a confirmed Target or equipment, or any quality decision | needs indexed sessions; Go to Sessions |
| Create a View | a View exists | needs indexed sessions; Go to Sessions (select sessions, then Create View) |
| Take the tour | `onboarding.tourCompletedAt` | Start the tour |

Flyout: header "Getting started · 2 of 5 done" with a progress bar; "Steps"
collapsible whose state persists (J18 S15); menu "Remove Getting started…" →
ConfirmDialog (restore from Settings › About). Items tick only from catalog
state, never manually; a polite live region announces progress. Spotlight (J18
S12-S13) is not built: jump links navigate instead (motion dial 2, and the
target controls belong to other tracks).

### Orientation tour (Overlay) · J18 S1-S5 adapted to the current IA

Auto-opens once when `completedAt` is set and `tourCompletedAt` is empty; Finish
and Skip both record `tourCompletedAt` (one-time). Modal: the backdrop blocks
clicks; only Next, Back, Skip tour and Escape act. Each stop navigates to its
page and anchors beside the sidebar item.

1. Targets: "Your library starts here. Each Target shows captured, usable and
   Unreviewed integration by channel, with its Projects, Views and plans."
2. Sessions: "Every indexed session, one per filter, exposure and equipment.
   Inspect the evidence, confirm Targets and equipment, and select sessions to
   create a View."
3. Calibration: "Masters and raw calibration sets, grouped by camera, settings
   and channel. PlateVault shows compatibility; it never builds masters."
4. Projects: "Optional goals with a capture checklist. A Project never moves
   files and never blocks creating a View."
5. Views: "A View is a named, reviewed set of frames. Review frames, accept
   calibration and prepare inputs for PixInsight, Siril or another app."
6. Getting started: "This checklist ticks itself from what you do. Open it any
   time, or remove it from its menu." (Getting started removed: anchors to
   Settings, "Restore it in Settings › About.")

## Known gaps

- Spotlight find (J18 S12-S13) is replaced by jump links (see above).
- Per-page checklist groups (J18 S7) do not apply: HLD §14 fixes five items.
- Moon-avoidance bands and planner tunables (J15 S9, J10 S5) belong to planning
  (T5) and are out of T1 scope.
- Remap verification is synchronous in the prototype; production hashes as an
  operation.
