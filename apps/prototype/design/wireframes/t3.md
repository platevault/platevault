# T3 wireframes: View workspace and frame review

Owner: track T3. Scope: specs 066 (VSEL) and 067 (PIX); journeys J21, J22, J25;
product flow B4, C1-C6, D1-D6, G. Binding sources: `../HIGH-LEVEL-DESIGN.md`
(routes §4, layout §6, tokens §7, components §8, states §9, copy §10, keys §11).
Every number below is fixture data. Widths reviewed: 1280 and 1024 CSS px
(content 1056 / 800 px with the sidebar expanded).

## Shared rules for every T3 screen

- One View workspace, no wizard (VSEL-FR-02). The layout owns the `h1` (View
  name); each area renders `PageHeader level={2}`; area sections use `h3`.
- Membership shown anywhere is `view.draft ?? latest revision`. Edits write the
  draft through `commit()` without `expect`; **Save View** is the revisioned
  commit (`expect` on the View). A draft equal to the latest revision is
  dropped (`draft: null`), so T4's "Save View first" gate reads true state.
- Library quality changes only through the three scoped confirmations
  (Mark included frames usable, Mark unusable in library, Reject for Project),
  each a `ConfirmDialog` that names scope, count and what stays unchanged.
  Saving, preparing, filtering and measuring never change quality.
- Unknown is never zero: `UnknownValue` for Position unknown, FOV unknown, Not
  measured, Not chosen. Offline or unreadable members are named unresolved or
  Unavailable, never removed.
- Prototype honesty: the frame preview is a synthetic raster drawn from fixture
  pixel facts and says so; the CSV file chooser is labelled simulated.
- Shortcuts (Frames area only, off while typing, off with single-key shortcuts
  disabled): `J` next frame, `K` previous frame, `X` exclude the current frame
  from this View. Each has a visible button and a palette entry.

| State | Behaviour and copy |
|---|---|

```

| State | Behaviour and copy |
|---|---|
| default | Area nav is links (`aria-current="page"`), not ARIA tabs (no forced order). |
| saved / unsaved | SaveState badge: "Saved" only when there is no draft and a revision exists; otherwise "Unsaved changes". **Discard…** shows while there is an editable draft: it returns to the saved revision, or removes a never-saved View and goes to Views (ConfirmDialog). |
| error (write failed) | SaveState "Not saved" + Retry + "Save View was not saved: the catalog write failed. Your change is kept on screen; choose Retry." The status stays Draft/previous revision. |
| error (stale) | SaveState "Changed elsewhere" + **Review current revision**; Save View is disabled with "Review the current revision first." until the user reviews. The review Notice "Reviewed: the View changed elsewhere" says what changed: the saved membership revisions and their diff, or that only the View record changed. Edit details refused as stale offers **Use current details** (reloads the fields), never a blind resubmit. |
| recovered draft | After a restart, a draft not touched in this session shows Notice "Recovered unsaved changes" with the diff ("1 frame restored to the View") and **Resume editing** / **Discard changes**. Until resumed, the summary shows the last committed revision (D08, J22 S16); a never-saved View says its draft is shown read-only. Every membership edit is refused until Resume, whatever control calls it. Resume hands focus to Save View. |
| complete | Notice "This View is Complete. Membership edits are refused while it is Complete." · **Reopen View…** (ConfirmDialog: clears Complete; Results, cleanup records and preparations unchanged). Edit controls are disabled with that visible reason; Clear selection is refused beside the bar with the same reason and writes nothing. |
| changed inputs | After a revision adds frames that the prepared revision lacks: Notice "Revision 4 adds 10 frames that need review" · **Review frames** · **Review calibration**; "Prepared revision 3 and its 208 entries are unchanged." (VSEL-AC-12, J25 S5) |
| unresolved | Summary names "24 unresolved (12 Sep OIII, Cold-1 captures offline)". |
| empty | Not found View: EmptyState "This View does not exist" · **Go to Views**. |
| hover / focus-visible / active / disabled | Buttons per base-nova. Save View is disabled while there are no unsaved changes, a recovered draft awaits Resume or Discard, or the View is Complete; it stays in the tab order (`aria-disabled`) with the reason as visible text beside it ("No unsaved changes."). |
| loading | N/A: synchronous store. |
| selected | Current area link `aria-current="page"` with the inset accent bar. |

Edit details dialog: View name (required), Project (None = standalone),
Application profile (Not chosen + profiles). Writes with `expect` (D08).

Journey steps: J21 S1, S2, S9; J22 S16; J25 S4, S5.

│ ☑ 26 Sep 19:55 OIII 300 s RedCat… ✓  35 2h 55m Avail 0.07° Covers 100% 35 Unrev  Not measured Geometry suggestion │

│ 28 Sep Ha · 56 frames · 4h 40m        │ [framing ▭] [footprints]   │
│ FOV from confirmed equipment 5.38°×3.60°│ Not drawn: 24 Sep          │
│  6248×4176 px · 250 mm · 3.76 µm · bin 1│ (Position unknown)         │
│ Footprint covers 100% (threshold 50%)  │                            │
│ OBJECT NGC 7000 (label only)           │                            │
└────────────────────────────────────────┴────────────────────────────┘
```

Rules: candidates are light sessions near the View's framing (≤ 5°), sessions
associated with its Target, sessions with Position unknown, and every selected
session; the "Near <Target>" scope is a removable chip. Preselection (a
Project chosen, however New View was reached) needs a footprint covering ≥ 50 % of the framing or a panel
(`MIN_FOOTPRINT_OVERLAP`) and confirmed Project equipment. Pointing-only
sessions show distance, "Pointing only", and are never preselected. OBJECT is a
label, never evidence. A View with no Project or Target framing shows "No framing"
for the distance of sessions with pointing; "Position unknown" means no RA/DEC.

| State | Behaviour and copy |
|---|---|
| default | Preselected rows checked with reason "Geometry suggestion". |
| hover / focus-visible / active | Row hover fill; session button and checkbox rings; ↑/↓ move between rows. |
| selected | Checked rows `bg-primary/10`; the open-evidence row `aria-current` + inset bar; its footprint draws thick. Sky coverage takes clicks on footprint outlines and lists every drawn footprint as a button (`aria-pressed` on the current one), because near-coincident footprints share most of their area; selected outlines are solid primary, unselected dotted muted-foreground (≥ 3:1). |
| empty (filtered) | "No sessions match these filters" · "Filters change the list, not the selection." · **Clear filters**. |
| empty (no candidates) | "No light sessions near this Target yet" · **Show all light sessions**. |
| disabled | Complete View: checkboxes disabled, reason in the area header; Clear selection is refused beside the bar. **Select matching** stays focusable and names why it is disabled: "Set a filter first" (with no filter it would select every listed session, Offline and other-camera included) or "Every match is selected". |
| error | Draft write failed: ActionError under the selection bar with Retry; the checkbox shows the committed state. |
| offline / unresolved | Notice "12 Sep OIII is offline" · "Its 24 frames are unresolved members: last-observed counts, not verified." · **Locate a copy** (→ `/settings/locations?locationId=`), **Open Storage**, **Remove from draft**. After Remove from draft, Include readable frames or Clear selection, focus moves to the table's select-all checkbox (WCAG 2.4.3). |
| loading | N/A: synchronous; no async lookup here. |

Filters popover: Channel, Night, Started from/to, Exposure min/max (s),
Equipment, Quality state, Location, Availability, Missing OBJECT; "More
metadata": Target, Camera, Gain, Offset, Binning, Temperature min/max (°C).
Each active filter is a chip; the chip row announces "N matching sessions".

Journey steps: J21 S1-S9 (C1-C6), J22 S13a, J25 after S5.

| State | Behaviour and copy |
|---|---|
| default | Opening the area measures nothing (PIX-AC-06, J21 S5). The bar names how many frames are not measured and offers **Review frames** (primary). Review covers every readable member; when some are excluded it says so ("Review covers 224 readable frames: 218 included, 6 excluded."). |
| loading (measuring) | After **Review frames**: cached values verify first ("Verifying cached values"), then the rest measure; progress bar with stable name "Measurement progress", "64 of 214 frames"; rows read **Pending**; the preview and selection stay usable (PIX-AC-01). Leaving Frames does not stop it; **Cancel** does. The operation names no View in its scope, so Mark complete never waits for a measurement (D09). |
| canceled | "Measurement canceled: 64 of 214 frames reached; 150 not measured." · **Review frames** reuses the values already computed and measures the rest (J22 S4); unfinished rows read **Not measured**. |
| interrupted | After a restart: "Measurement interrupted by a restart: 15 of 194 frames" · **Review frames** resumes the same run · **Cancel**. Queued rows read **Not measured** until it resumes. |
| selected | Current frame: row `aria-current`, plot marker ◆, preview title — all three agree (PIX-AC-07). Checked frames for bulk actions are separate and live only while the page is open: they are never persisted, so a restart never leaves a bulk action armed. |
| hover / focus-visible / active | Row hover; plot points show a hover ring (pointer only; the table is the keyboard path); preview focus ring; arrow keys pan at 1:1 and 2:1. |
| disabled | Bulk actions stay focusable when disabled and name the reason under the bar ("Restore to View needs an excluded frame in the selection."); Previous/Next at the ends say "First frame shown" / "Last frame shown". Complete View: **Review frames** disabled with "Complete Views are not measured; Reopen first.", membership and quality actions disabled with the read-only reason. J/K and Previous/Next follow the table's current sort. Clear selection keeps focus on the table's select-all checkbox. |
| empty | No sessions selected: EmptyState "No frames to review yet" · **Choose sessions**. Filters hide every frame: "No frames match" · **Clear filters**. |
| error | Draft or quality write failed: ActionError beside the bar with Retry; import write failed: error in the import dialog with Retry. |
| failed fit | Star detail "Failed fit · Saturated: peak at 65,535 ADU" and no FWHM or HFR number (PIX-AC-03). |
| changed content | Row quality "Changed content". Its cached and imported values stop applying ("Not measured", FWHM imported "None") until **Review frames** measures it again from its current bytes; the earlier built-in and imported values move to history for the earlier content ("History: 1 earlier measurement for other content"). Restored bytes that rehash to the earlier digest bring both back (PIX-AC-10). Every import is stamped with the digest of the bytes it was mapped to (PIX-FR-06), so values imported before any built-in run never apply to later bytes. |
| invalid samples | Preview marks them; metric warning "140 invalid samples (NaN or ±∞) masked from this metric" (PIX-AC-08). |
| CFA | Basis "linear, CFA RGGB mosaic plane"; preview draws the mosaic as recorded, never debayered (PIX-AC-09). |

Confirmations (all `ConfirmDialog`):
- **Mark 208 frames Usable in the library** — "This will: mark 208 frames Usable (library scope); raise NGC 7000 usable integration to Ha 9h 15m, OIII 8h 05m." Unchanged: "View membership (208 included, 6 excluded)", "Source files and headers", "Other Views". Excluded selected frames are named as skipped.
- **Mark 1 frame Unusable in the library** — unchanged: "This View's membership", "Project rejection records".
- **Reject 1 frame for Project NGC 7000 HOO** — unchanged: "Library quality (stays Unreviewed)", "Target usable totals", "This View's 208 included frames".

Import measurements dialog: step 1 choose a CSV ("Prototype: simulated file
chooser listing CSV files on mounted volumes"); step 2 mapping review with
columns (CSV column · unit · maps to · status) and rows (matched by path,
unmatched, ambiguous); **Import N matched rows**. Approved column: "Not
imported: rejection decisions stay yours." PSFSignalWeight: "Unavailable: no
units and no PlateVault equivalent." After import, "Imported measurements"
lists rows needing review; the ambiguous row offers **Attach to** one candidate.

Journey steps: J22 S1-S11, S13-S16 (D1-D6); S12 is T2 (Project).

## States not applicable in T3, with reasons

- Loading skeletons on every screen except measurement: store reads are
  synchronous (HLD §9); measurement is the only asynchronous work, shown with
  progress and Pending rows.
- Paging in the session table: fixture tables stay under ~800 rows (HLD §14);
  the frame keeps its scroll, so J21 S7's "change page" step has no page to
  change and selection survives sorting and the sky toggle instead.
